# Customer Churn Prediction & Analysis

## 📌 Project Overview

This project analyzes customer churn data to identify patterns and factors that influence customer churn.

The project uses Python for data cleaning and exploratory analysis and Power BI for creating an interactive dashboard to visualize churn trends and customer insights.

## 🎯 Objectives

- Analyze customer churn patterns
- Clean and preprocess the customer dataset
- Explore factors affecting customer churn
- Generate meaningful business insights
- Build an interactive Power BI dashboard
- Present key KPIs and churn trends

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Power BI
- DAX
- Power Query
- Git & GitHub
